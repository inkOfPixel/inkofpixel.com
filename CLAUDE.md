# inkofpixel.com

Static site generated by `src/build.mjs` (Node, ES modules, no framework). Read `README.md` for the layout of the repository.

## Working on the site

- Preview with `npm run dev` (port 4321). Check every visual change in the browser at desktop (1440px) and phone (390px) width before calling it done.
- Every page exists in English and Italian. When you change copy, change both languages. English is the default language and lives at `/`, Italian at `/it/`.
- Copy belongs in `content/`. Short interface labels (navigation, buttons, section titles) belong in `T` inside `src/lib/site.mjs`. Do not hardcode text in templates.
- Do not change existing URLs. If one must change, add a redirect in `Caddyfile`.
- The site is static. The only server-side code is the contact form handler in `server/`; keep it that way unless asked.

## Common tasks

- New blog post: add `content/posts/<slug>.md` following an existing post (front matter with `title`, `author`, `date`, and a `locales` list with `language`, `title`, `excerpt`, `featuredImage`, `heroImage`, `body`). The URL comes from the localized title.
- New case study: add `content/projects/<slug>.md` following an existing one. In the body, text before the first `## ` heading is the intro, the first quote becomes the pull quote, every `## ` heading opens a chapter, and a last chapter titled "Results" / "I risultati" becomes the highlighted panel.
- Home clients: edit `clients.marquee` and `clients.featured` in `content/static-pages/home.json`. A featured client links to a case study only when it has a `project` slug.
- Images go in `static/assets/` and are referenced as `/assets/<file>`. After adding images run `npm run images`: it resizes them, converts animated GIFs to MP4 clips and fixes the references in `content/`. Never commit a GIF.
- A Markdown image that points to an `.mp4` renders as a silent looping clip; its `<name>.poster.jpg` must sit next to it (the script creates it).

## Design rules

- Black ink on white paper, no other colours. Photos are grey until hovered.
- There is a light and a dark theme (`data-theme` on `<html>`, switch in the header). Never hardcode a colour in a component: use the tokens at the top of `site.css` (`--ink`, `--paper`, `--soft`, ...), which the dark theme swaps. Check both themes after a visual change.
- Typefaces: Bricolage Grotesque for text, Instrument Serif italic for accent words (`<em>`), system monospace for the small code tags (`<servizi>`, `// note`).
- Motion is part of the design: reuse the existing classes (`in`, `rv`, `line`, `accent`, `row`, `card`) before inventing new effects, and keep `prefers-reduced-motion` working.
- Never use the em dash character in copy.
